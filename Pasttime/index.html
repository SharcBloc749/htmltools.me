Pasttime

A tiny realtime database for small projects — chat apps, guestbooks, leaderboards, todo lists. Create a database, copy its ID, and hand it to any AI assistant. It'll know exactly what to build.

How to use Pasttime

Pasttime gives you a tiny JSON database for small web projects. Create one, copy its ID, and give that ID straight to an AI — it already contains everything the AI needs to build with it.

How it works
?
What's actually happening ▼

Each database is a collection of "records" grouped into named buckets ("collections") — similar in spirit to Firebase or Firestore, but much simpler. There's no schema to set up.

Your database's ID is a single string that already encodes where the data lives and how to talk to it. Nobody needs to send you or your AI any extra URLs — the ID is the whole spec.

Pasttime only stores which databases belong to you. The database content itself lives elsewhere and is fetched fresh every time — nothing sensitive sits in your account beyond your ownership list.

ℹThere's no live push/websocket connection. Apps built on Pasttime should re-check the database every couple of seconds to simulate "realtime" — the AI helper already knows to do this.
Getting started
1
Create a database ▼

Click + New database, give it a name, and choose whether reads should be open to anyone (public) or require the key too (private). You can make up to 7.

2
Copy the database ID ▼

Every database has an ID card on its page. Copy the whole string — it already contains everything an AI needs to know to use it correctly.

3
Hand it to an AI ▼

Paste the ID into ChatGPT, Claude, or any AI assistant and say something like: "Build me a chat app using this database: [paste ID]". The AI will decode it and write working fetch() code — no SDK to install.

4
Use the built-in AI helper ▼

Click the round icon in the bottom-right corner from any database page to ask questions or get code without leaving Pasttime.
