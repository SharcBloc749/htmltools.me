What runs here?
HTML, CSS, JavaScript, and TypeScript (including local module imports). Python 3 runs with its standard library in an isolated worker; Stop can terminate it. Python starts fresh on each run; third-party Python packages and interactive input are not included.

Markdown, JSON, SVG, images, and text can be previewed. Any other UTF-8 text file can be edited and downloaded, but PHP, Java, C/C++, shell scripts, and other server or native languages need their own runtime.

Import limits: 250 files, 2 MiB per file, 16 MiB per project. ZIP folder paths are preserved. Use full HTTPS ESM URLs for browser-compatible packages; npm installation and a backend are not provided. Preview code runs in a sandbox without access to your sign-in or local workspace storage.
