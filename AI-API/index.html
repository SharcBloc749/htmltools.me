What it is

Three moving parts, all documented.

Everything below is implemented in the Worker in this repository. Nothing is proxied to a paid provider you did not connect yourself.

01 — Surface

OpenAI-compatible chat

GET /v1/models and POST /v1/chat/completions with OpenAI request, response, streaming and error shapes. Bearer key authentication.

02 — Compute

Workers AI, or your Groq key

Free-pool models run on Cloudflare's edge GPUs. Connect your own Groq key and groq model ids run on your account and your limits instead.

03 — Control

Keys, usage, revocation

Hashed keys with password-gated recovery, immediate revocation, per-key and per-account limits, and a roster synced to a private repository you own.

Quickstart

Working request in one paste.

Create a key in the dashboard, then use it exactly like an OpenAI key.

curl
curl /v1/chat/completions \
  -H "Authorization: Bearer ht-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "@cf/meta/llama-3.1-8b-instruct",
    "messages": [{"role": "user", "content": "Explain this API in one sentence."}]
  }'
Some apps want the base URL with /v1, others add it themselves. If a tool fails with a 404, try the origin without /v1.

Limits

Small, shared, and honest about it.

The free pool is a courtesy, not a service level. Volume belongs on your own provider account.

The free pool cannot carry continuous traffic. 6,000 Neurons is roughly 350 short 8B replies a day — far below 10 requests per minute sustained. When it is gone, free-pool requests return HTTP 429 with free_pool_exhausted until 00:00 UTC.
The practical path at volume is your own Groq key. Groq's free plan is rate-limited per model but not billed to htmltools.me, so those requests do not touch the shared pool.

Operators can change every number in wrangler.toml; this page shows the documented defaults.

Privacy

What we store, and what we never see.

Prompts are not stored

The gateway keeps counters (requests, tokens, estimated Neurons) and rotates request ids. It does not persist message content. Workers logs carry metadata only, because the code only ever logs metadata.

Prompts do leave Cloudflare

Free-pool prompts are processed by Cloudflare Workers AI. If you connect Groq, those requests go to Groq under your account. Their terms apply to that processing.

Secrets stay server-side

Keys authenticate against salted hashes; a recovery copy is encrypted with AES-256-GCM and only decrypts after you confirm your password. A connected Groq key uses the same encryption, and you can delete it at any time.

SiloAI

A quiet assistant that answers the first question.

SiloAI sits on every AI-API page. Ask it for the base URL, why a request returned 429, or how streaming differs between models. It runs on a small Workers AI model, is capped at 15 messages per account per day, and requires a signed-in account so it cannot be used anonymously.

SiloAI never asks for keys or passwords. If a support message asks you to paste an API key into a chat, do not.
