? What this does
1. You sign in. Your current Website Encryption projects are read from Firebase and decrypted locally in this browser tab — plaintext never leaves it.
2. You paste a GitHub token. Each project is re-encrypted with a master key (AES-256-GCM) and written directly to your private repo under Website-Encryption/<your@email.com>/ — the folder is created automatically.
3. When everything is green, one click deletes the old Firebase copies. Firebase is then used for sign-in only.
